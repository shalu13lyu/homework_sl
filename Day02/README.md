# Day 02 — Python, VS Code, Git and GitHub

## Assignment Overview

In this assignment, I practiced creating and running Python files using VS Code and managing my code with Git and GitHub.

## My Workflow

### 1. Preparing the Environment

I installed VS Code and Git on my Windows computer and checked that Git was installed using:


### 2. Creating Python Files

1. Opened VS Code.
2. Selected File → New File → Python File.
3. Wrote Python code.
4. Saved the file with the `.py` extension.


### 3. Writing and Running Python Code

I practiced writing Python programs, including:
- A Hello World program.
- A BMI calculator using invented data for five people.
- A calculator for matrix operations.

I learned about variables, lists, dictionaries, loops, mathematical operations and the `print()` function.

### 4. Working with Git and GitHub

1. Opened Source Control in VS Code.
2. Selected the files I wanted to commit.
3. Clicked Commit.
4. Wrote a commit message in the `COMMIT_EDITMSG` editor.
5. Saved the message and completed the commit.
6. Clicked Sync Changes.
7. Opened GitHub to check that my files appeared in the repository.

### 5. Managing Files

I also practiced deleting an old Python file and committing the deletion.

I learned that:
- **Save** stores changes on my computer.
- **Commit** records changes in Git history.
- **Push** uploads commits to GitHub.
- **Sync Changes** synchronizes my local and remote repositories.

## What I Learned

I learned how to create Python files, run programs, organize assignment folders, use Git version control, and upload my work to GitHub.
